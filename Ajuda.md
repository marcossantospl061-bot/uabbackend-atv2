# Catálogo de Heróis – Marvel e DC

Projeto em Node.js com Express.

## Como executar

```bash
npm install
node index.js
```

Acesse: http://localhost:3030

## Rotas

- `/` – Página inicial
- `/marvel` – Página da Marvel
- `/dc` – Página da DC
- `/personagem/:empresa/:nome` – Página do personagem (ex.: `/personagem/marvel/Thor`)
